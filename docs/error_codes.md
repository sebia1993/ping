# 오류 코드와 조치 방법

화면에 오류 코드가 표시되면 먼저 측정을 중지하고 아래 조치를 확인합니다.
세션 파일이나 로그를 삭제하기 전에는 원본을 다른 폴더에 복사해 보관합니다.

진단 로그 기본 위치:

```text
%LOCALAPPDATA%\MultiPingCheck\logs\multipingcheck.log
```

| 오류 코드 | 의미 | 우선 조치 |
|---|---|---|
| `APP_STARTUP_FAILED` | 프로그램 초기 화면 또는 저장 폴더를 만들지 못했습니다. | 프로그램을 다시 실행하고, 사용자 로컬 폴더의 쓰기 권한과 남은 디스크 공간을 확인합니다. |
| `APP_UNEXPECTED_ERROR` | 실행 중 예상하지 못한 내부 오류가 발생했습니다. | 프로그램을 다시 실행합니다. 반복되면 오류 발생 시각과 진단 로그를 함께 확인합니다. |
| `WORKER_UNEXPECTED_ERROR` | 측정 작업에서 처리되지 않은 오류가 발생했습니다. | 측정을 중지한 뒤 다시 시작합니다. 같은 대상에서 반복되면 해당 대상 수를 줄여 재현 여부를 확인합니다. |
| `SESSION_LOG_WRITE_FAILED` | 측정 결과를 세션 CSV에 저장하지 못했습니다. | 디스크 공간, 백신 차단, 파일 잠금, 폴더 권한을 확인합니다. 기존에 저장된 파일은 삭제하지 않습니다. |
| `SESSION_LOG_CORRUPTED` | 세션 CSV에서 손상되거나 불완전한 행을 발견했습니다. | 원본 파일을 보관합니다. 일부 데이터는 화면에서 복구될 수 있지만 불완전한 내보내기는 차단됩니다. |
| `SESSION_INDEX_REBUILT` | 세션 목록 파일을 읽지 못해 CSV를 기준으로 목록을 재구성했습니다. | 세션 수와 시작 시각을 확인합니다. 반복되면 진단 로그와 저장 폴더 권한을 확인합니다. |
| `SESSION_RECOVERED_WITH_SKIPPED_ROWS` | 세션 목록의 일부 잘못된 행을 제외하고 복구했습니다. | 누락된 세션이 없는지 확인하고 세션 저장 폴더를 보관합니다. |
| `SESSION_INDEX_FINISH_FAILED` | 측정 종료 상태를 세션 목록에 반영하지 못했습니다. | 프로그램을 다시 실행해 세션이 `Pause` 또는 복구 상태로 표시되는지 확인합니다. |
| `ROUTE_LOG_WRITE_FAILED` | 경로 변경 기록 저장에 실패했습니다. | 디스크 공간과 파일 잠금을 확인합니다. 기본 최종 대상 ping 측정은 계속될 수 있습니다. |
| `EXPORT_WRITE_FAILED` | CSV 또는 XLSX 파일을 저장하지 못했습니다. | 같은 파일을 Excel에서 닫고, 쓰기 가능한 다른 폴더와 새 파일명으로 다시 저장합니다. |
| `EXPORT_UNEXPECTED_ERROR` | 내보내기 처리 중 예상하지 못한 오류가 발생했습니다. | 원본 세션은 유지한 채 프로그램을 다시 실행하고 내보내기를 재시도합니다. |
| `SESSION_GRAPH_LOAD_FAILED` | 저장된 전체 측정 구간을 그래프로 읽지 못했습니다. | 최근 구간을 확인하고 세션 파일 잠금 또는 손상 여부를 점검합니다. |
| `ALERT_ACTION_QUEUE_FULL` | 외부 알림 전송 요청이 처리 속도보다 많이 쌓였습니다. | REST·메일 대상의 응답 상태를 확인하고 반복 알림 조건을 점검합니다. |

## 공유할 때

외부 개발 환경으로 자료를 전달할 때는 실제 회사 IP, 호스트명, 사용자명, 장비 목록,
인증정보와 원시 장비 출력을 제거합니다. 가능하면 오류 코드, 발생 시각, 대상 개수,
재현 순서와 민감정보를 가린 화면만 공유합니다.
